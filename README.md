# バスカヴィル家の犬 ― 読者・雫の事件簿

コナン・ドイル『バスカヴィル家の犬』（1902年・パブリックドメイン）の世界に、読者の **雫** が入り込む3D推理ゲーム。
ブラウザで遊べる。スマホでは縦向き・全画面で、ホーム画面に追加するとアプリとして遊べる（PWA・オフライン可）。

## ゲームの考え方

- **文字を読む量を減らす**：手がかりは文章ではなく、物そのものを手に取って調べる（なぞって回し、光る所をタップすると寄って見える）。人物は3Dと顔のアイコン、手がかりは絵のカードで示す
- **思ったとおりに動ける**：部屋の中の物はたいてい調べられ、一言の反応が返る。その中に本当の手がかりが混ざっている
- **物語は原作どおり**：雫は物語に介入しない。誰にも見えず、聞こえない。**ワトソンにだけは見え、話せる**（語り手のワトソンが、読者に語りかけるのは自然なことなので）
  - ワトソンと話せるのは、ほかの人がいないときだけ。人前では、ワトソンは目くばせやうなずきで応える
  - ワトソンは先のことを知らない（本の中の、今のページを生きている）
  - 雫が正しく見抜いて伝えても、ワトソンの行動は原作どおり。ゲームの楽しみは「ワトソンより先に、ホームズと同じ答えにたどり着く」こと
- **台詞**：英語の原作から新しく書き起こしたもの。既存の日本語訳は使わない（翻訳には別の権利があるため）

## 推理の作り（フェアに解けるように）

原作のホームズは、当時のイギリスの常識や専門の知識を使って推理する。ゲームでは、プレイヤーが先に答えるので、**その知識と事実をすべて先に渡す**。

- **言葉**：台詞と説明は、今の日常の言葉で書く（例：石突き→杖の先、炉棚→暖炉の上の棚、往診→患者の家を回る、相続人→跡継ぎ、木戸→小さな門）。物語に欠かせない言葉は残し、推理ノートの **「用語」** で説明する
- **ワトソンが教える**：ワトソンは医者で、原作でも同じ物を見ている。教えるのは **知識と事実だけ**（結論は言わない）。手がかりを見つけるとひと言添え、話しかけると「M.R.C.S. って？」「病院のお医者さんのこと」などを選んで聞ける。ホームズがいる場面では話せないので、そのときは「用語」と、調べたときの説明で補う
- **物に目安を入れる**：歯形には目盛り（約4cm）。犬の選択肢には口の幅（3cm／4cm／6cm）
- **問題を一歩ずつに**：「どんな人？」を「贈られたのはどんなとき？」「どんな医者？」に分けるなど、手がかりから一歩で届く問いにする
- **答え合わせに解説**：問題ごとに、根拠になった手がかりの絵と、考え方を出す

## 雫（読者）

- 推理小説オタク。この世界に入れたことに、ずっと興奮している
- 3Dモデルは `assets/vrm/shizuku2.vrm`（VRoid Studio で作成した元のファイル）。ゲームでは、これを `tools/vrm_lite.py` で軽くした `assets/vrm/lite/shizuku2.vrm`（テクスチャ512px・約4.7MB）を使う。顔のアイコンは `assets/faces/shizuku2.webp`（`tools/face_icon.mjs` で VRM から撮る）
- モデルを差し替えたら：`python3 tools/vrm_lite.py assets/vrm/shizuku2.vrm assets/vrm/lite/shizuku2.vrm --tex 512 --no-morph-normals` と `node tools/face_icon.mjs`（HTTPサーバーを動かしてから）
- 雫は『バスカヴィル家の犬』を今夜はじめて読んでいる。だから犯人も結末も知らない（ほかのホームズ作品は全部読んでいる）
- ほかの人物（ワトソン・ホームズ・モーティマー・犬）は、プログラムで組み立てるローポリの仮の人形（`js/engine.js` の `makeFigure`）。VRM ができたら差し替える

## 第1章「シャーロック・ホームズ氏」

1. **オープニング**：本のページが光り、雫がベーカー街221B の居間に入り込む
2. **ワトソンとの出会い**：ワトソンだけが雫に気づく。ゆうべの客が置いていったステッキを、ホームズが起きる前に二人で推理することに
3. **自由に調べる**：ステッキを手に取って、3つの手がかり（銀の帯の献辞「C.C.H.」と1884年／すり減った石突き／犬の歯形）を見つける。部屋の物（ペルシャ・スリッパのたばこ、炉棚にナイフで留めた手紙、「V.R.」の弾痕、石炭入れの葉巻、銀のコーヒーポットなど）も調べられる
4. **推理**：手がかりがそろったらワトソンに話しかけ、絵の選択肢で4問に答える（C.C.H. とは／杖が贈られたのはどんなとき／どんな医者／犬の大きさ）。その前に、ワトソンに当時の知識を聞ける
5. **原作の場面**：ホームズが起きてくる（雫は見えていない）。コーヒーポットに映るワトソン、ワトソンの推理、ホームズの訂正
6. **答え合わせ**：雫・ワトソン・ホームズの答えを並べる
7. **窓の外**：「その犬は巻き毛のスパニエルだ」。窓から通りを見下ろすと、モーティマー医師と犬が来ている
8. **モーティマー医師の来訪**で第1章おわり。「第2章へ」でそのまま続く

## 第2章「バスカヴィル家の呪い」（ver 0.3）

原作の第2章と第3章の前半。ホームズが同じ部屋にいるので、ワトソンとは話せない（最後に、階段で二人きりになる）。

1. **古文書**：モーティマー医師の手元を、雫が自分でのぞきこむと始まる。1742年の伝説（ヒューゴ・バスカヴィルと魔犬）を **影絵** で見せる（7場面。文字は一場面に一行）
2. **新聞**：地元の新聞の紙面に、要点を絵のカードで1枚ずつ足していく（散歩の習慣／荒野への木戸／足跡が「つま先」に／死因は心臓の発作）
3. **イチイの並木道**：モーティマー医師の話を聞きながら、雫が思い描いた現場を歩いて調べる（夜・月明かり。ほかの人はいない）
   - 手がかり：荒野への木戸（錠）／木戸の前の葉巻の灰2か所／木戸から先の、つま先だけの足跡（歩幅が広い）／倒れていた場所
   - **道の端の、大きな犬の足跡**は印を出さない。近くを歩くと名前が出るので、気づけば手がかりになる（モーティマー医師が明かす前に見つけられる）
   - 4つそろうと「話にもどる」
4. **推理**（3問）：つま先の足跡の意味／葉巻の灰の意味／何から逃げたか。「手がかりを見直す」で、もう一度並木道へ
5. **「ホームズさん……巨大な犬の足跡でした」**：ホームズの問いと見立て → 答え合わせ（雫・新聞・ホームズ）
6. ヘンリー卿の到着の知らせ、モーティマー医師の退出、ホームズの「いちばん強い刻みたばこを」
7. **階段で**：ワトソンと二人きりで話す（犬の足跡を見つけていれば、会話が変わる）

## 第3章「ヘンリー・バスカヴィル卿」（ver 0.5）

原作の第3章の後半と第4章。

1. **その夜**：たばこの煙で真っ白な部屋。ホームズが取り寄せた **ダートムアの地図** を、場所をタップしながら見る（バスカヴィル館・グリンペン村・ラフター館・メリピット荘・荒野の農家・刑務所）
2. **翌朝、ヘンリー卿**：ホテルで受け取った、新聞の文字を切り抜いた手紙「命と正気が大事なら、荒野に近づくな」
3. **手紙と封筒を調べる**（手がかり5つ）：切り抜きの文字／手書きの「moor」／2回に分けた切り口／崩した宛名と消印／かすれたインク
4. **タイムズ紙の社説で、手紙の言葉を探す**：記事の単語をタップして見つける。「moor」だけは記事に無い
5. **推理**（3問）：なぜ「moor」だけ手書き？／宛名を書いた場所／送り主の気持ち → ホームズの見立て → 答え合わせと解説
6. **片方だけ消えた新品の靴**
7. **リージェント街**：ホームズたちと一緒に、ヘンリー卿の後を歩いてつける。後ろを同じ速さでついてくる **辻馬車2704** と、中の黒ひげの男に、ホームズより先に気づけるか（気づけば成績の★）。雫が遅れすぎると、一行は待つ
8. **使い走りの事務所の前**：ホームズが中にいる間、ワトソンと二人で話せる（手紙・靴・馬車のことを選んで聞く）

## 操作

- 移動：画面をなぞる（どこからでも）／矢印キー・WASD
- 調べる・話す：物や人をタップ（そこまで歩いて調べる）／スペース・E で近くの物
  - 指の近くに調べられる物が2つ以上あるときは、一覧が出るので選ぶ
- **カメラを回す・寄る**：右下の ⟲ ⟳ で90度ずつ回す（2本指でひねっても回る）。2本指で広げる・縮めると寄る・引く。カメラの側に来た壁や生け垣・建物は消して、中が見えるようにする（場所ごとの `walls`）。PC：Q・R で回す、ホイールで寄る
- **見回す（雫の目線）**：右下の 👁。雫の目の高さからの一人称になり、なぞって360度見回す。2本指で寄る。手の届く所（3.4m 以内）の物は、名札かその物をタップすると、歩かずにその場で調べられる。左上の「もどる」で戻る。場面が切り替わるときは、自動で戻る。PC：V（Esc でもどる）
- **誤タップ防止**（すべての選択肢・推理・タップ一覧・メニュー・確認の窓。`js/tap.js`）
  - 選択肢が出てから約0.4秒は押せない（その間はボタンが薄い。濃くなったら押せる）
  - ボタンの上で押し始めて、ボタンの上で離したときだけ決定。選択肢が出る前から触れていた指や、すばやい2回目のタップは無視される
  - 選んだボタンに ✓ を付けて少し光らせてから次へ。推理の次の問題は横から滑り込む
  - 台詞は、出てから0.3秒は送れない
- 印と名札：**金色の ✦ はまだ調べていない物**、**灰色の ✓ は調べ終えた物**（雫の近く3m以内に出る。いちばん近い物には名前の札）
- 推理の画面：手がかりの絵をタップすると中身が見られる。「← 前の問題」で戻れ、「手がかりを見直す」で部屋に戻って調べ直せる（答えは白紙に戻る。決まったら、またワトソンに話しかける）
- 右上の「推理ノート」：手がかり・人物・推理

## オフライン用データ

タイトルの「設定」→「オフライン用データ」で、ゲームの全ファイルを端末に保存できる（Wi-Fi のときに、まとめて）。

- 状態（未・一部・ダウンロード済み）と大きさを出す。途中で切れても、もう一度押せば続きから
- モバイル回線だと分かるときは確認を出す（iPhone は回線の種類を調べられないので、いつも一言そえる）
- 保存し終えたら、ブラウザに「消さないで」と頼む（`navigator.storage.persist()`）
- 保存したデータを使う係（Service Worker）がまだページを受け持っていないときは、「一度開き直して」と出す
- 仕組み：公開するファイルの一覧は `files.json`（`tools/make_manifest.py` が作る。`tools/bump_version.py` を実行すると作り直される）
  - プログラム（html・css・js・ライブラリ・アイコン）は版ごとのキャッシュ `homes-<版>`。最初に開いたときに自動でそろう
  - 大きなデータ（`assets/`）は版をまたぐキャッシュ `homes-assets`。中身が変わった物だけ取り直す（`files.json` のハッシュで比べる）
- タイトルに「オフラインで遊べます ✓」と出る

## ローカルで動かす

ES Modules と Service Worker を使うため、HTTPサーバー経由で開く。

```sh
python3 -m http.server 8080
# http://localhost:8080 を開く
```

## 公開（GitHub Pages）

リポジトリの Settings → Pages で、公開するブランチとフォルダ（`/ (root)`）を選ぶ。ビルドは要らない。

## スマホでアプリにする

- **Android（Chrome）**：タイトルの「設定・アプリにする」→「ホーム画面に追加」。ブラウザのままでも「はじめから」で全画面・縦向きになる
- **iPhone（Safari）**：共有ボタン →「ホーム画面に追加」。ホーム画面から開くと全画面で遊べる（Safari のままでは全画面にできない）

## 版を上げる

```sh
python3 tools/bump_version.py 0.2
```

`sw.js` のキャッシュ名が変わると、遊んでいる端末は次に開いたときに新しいファイルを取りに行く。タイトルの「設定」→「最新版を確かめる」でも更新できる（セーブは残る）。
